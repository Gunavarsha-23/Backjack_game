# Backjack_game

Welcome to the digital felt. This is a clean implementation of classic Blackjack (21) built entirely in Python. It's just you against the dealer. Who's going to bust first?

## 🎯 What's Inside?
* **Vegas Rules:** Full hand-value tracking, including Aces that automatically switch between 1 and 11 to keep you alive.
* **Smart AI Dealer:** The house plays by strict casino rules—hitting on anything below 17 and standing on a hard 17.
* **Instant Feedback:** Clean terminal updates that track every card dealt and every score in real-time.
